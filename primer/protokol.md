# Протокол голосового помощника

Сервис говорит по обычному HTTP. Поэтому к нему подключится что угодно:
Python, Node.js, Go, PowerShell, оболочка агента на любом языке.
Никаких ключей, регистраций и библиотек не нужно — только адрес.

Адрес по умолчанию: `http://127.0.0.1:18905`
Другой порт задаётся при запуске: `python golos_servis.py --порт 19005`

Сервис слушает **только 127.0.0.1** — из интернета он недоступен.
Это сделано намеренно: голосовая служба не должна быть видна наружу.

Все ответы — JSON, в кодировке UTF-8.

---

## 1. Узнать, что сервис жив

```
GET /состояние
```

Ответ:

```json
{
  "жив": true,
  "порт": 18905,
  "агенты": ["DENIS", "DMITRI", "IRINA", "RUSLAN"],
  "загружены_модели": [],
  "папка_моделей": ".../modeli"
}
```

`загружены_модели` пустой — это нормально при ленивой загрузке: модель
грузится при первом обращении к этому голосу, а не заранее.

Пример на PowerShell, без Python:

```powershell
Invoke-RestMethod http://127.0.0.1:18905/состояние
```

## 2. Сказать фразу

```
GET /сказать?агент=IRINA&текст=Привет&играть=0&скорость=1.0
```

Параметры:

| Параметр | Нужно | Что это |
|---|---|---|
| `агент` | да | Код голоса из конфига. Регистр не важен |
| `текст` | да | Что сказать. Нельзя длиннее примерно 3000 знаков |
| `играть` | нет | `0` — только создать файл, `1` (по умолчанию) — ещё и озвучить |
| `скорость` | нет | От 0.6 до 1.8. Если не указать, берётся скорость голоса из конфига |

Ответ:

```json
{
  "ок": true,
  "файл": ".../озвучка/IRINA.wav",
  "байт": 260140,
  "озвучка_секунд": 5.9,
  "синтез_секунд": 1.93,
  "всего_секунды": 6.63,
  "движок": "piper «irina»",
  "плеер": "не играл",
  "из_кэша": false,
  "скорость": 1.0
}
```

| Поле | Что это |
|---|---|
| `озвучка_секунд` | длина самого звука. Для wav — точно, по заголовку файла |
| `синтез_секунд` | сколько времени заняло произнесение |
| `всего_секунды` | сколько занял весь запрос, вместе с ожиданием |
| `из_кэша` | фраза произнесена заново или взята из кэша |
| `байт` | размер звукового файла |

**Первое и второе — разные вещи.** Фраза может произноситься за две
секунды, а звучать пять. Сверять правило «от 3 до 25 секунд» нужно с
`озвучка_секунд`, а не со `синтез_секунд`.

Для сетевых голосов файл в формате mp3, и его длину нельзя посчитать точно
без декодера. В этом случае `озвучка_секунд` будет `null`. Это честнее,
чем подставлять оценку.

Ошибки:

| Код | Когда |
|---|---|
| 400 | не переданы `агент` или `текст` |
| 404 | такого голоса нет; в ответе придёт список доступных |

## 3. Кэш

Ключ кэша собирается из текста, голоса, скорости и движка. Тот же текст
тем же голосом и той же скоростью **всегда** даёт тот же файл и отдаётся
из кэша, а не синтезируется заново.

Поле `из_кэша` в ответе показывает, откуда взят звук:

* `false` — фраза была произнесена заново;
* `true` — фраза уже звучала, файл взят из кэша.

Голосовые сообщения короткие и повторяющиеся, поэтому на второй раз
ответа почти нет времени.

Файл считается годным кэшем, только если он больше 1000 байт: пустой или
обрезанный файл никогда не будет выдан за готовый ответ.

## 4. Как подключить агента

Любой агент, который умеет делать HTTP-запрос, подключается в три строки.

### Python

```python
import primer_python as голос

рез = голос.сказать("Готово, работа закончена", "DENIS", играть=False)
print(рез["секунды"])
```

Полный пример с проверками: `primer/primer_python.py`.

### Любой другой язык

Запрос и разбор ответа те же самые. Пример на Node.js:

```javascript
const текст = encodeURIComponent("Готово");
const r = await fetch(`http://127.0.0.1:18905/сказать?агент=IRINA&текст=${текст}&играть=0`);
const рез = await r.json();
console.log(рез.озвучка_секунд, рез.файл);
```

### PowerShell

```powershell
$t = [uri]::EscapeDataString("Готово")
Invoke-RestMethod "http://127.0.0.1:18905/сказать?агент=IRINA&текст=$t&играть=0"
```

## 5. Правила, которые сервис уже соблюдает сам

* **Сообщение начинается с имени.** Имя подставляется автоматически,
  если текст ещё не начинается с него. В `govori.py` это можно отключить
  ключом `--без-имени`.
* **Длина от 3 до 25 секунд.** Вне окна выводится честная пометка, а не
  молчание.
* **Темп словами:** медленно 0.75, нейтрально 1.0, быстро 1.25.
  По умолчанию нейтрально.
* **Один и тот же ответ звучит одинаково**, потому что он кэшируется.

Служебная программа `govori.py` добавляет имя, следит за длиной и темпом.
Если агент говорит с сервисом напрямую по HTTP, эти правила он
соблюдает сам.

## 6. Если сервис не отвечает

| Что видим | Что делать |
|---|---|
| `Connection refused` | сервис не запущен: `python golos_servis.py` |
| Порт занят, сервис не стартовал | запустить с другим портом: `--порт 19005` |
| `404` на `/сказать` | код голоса не найден; взять верный из `/состояние` |
| Голос молчит, файл не создан | нет сети, а голос сетевой: сервис должен был переключиться на офлайн-голос. Если не переключился — проверить папку `modeli` |
